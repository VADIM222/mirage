Расход разрешается исключительно после отдельной проверки выбранного типа, текущего/следующего уровня, цены, предпосылок и очереди.

## Стройка

Новые отдельные параметры: `auto_prerequisites` и `create_missing`, оба по умолчанию выключены. Существующий профиль не включается автоматически.

`development.py` обходит настоящую цепочку следующих уровней, учитывает уже принятые таймеры, отдельные экземпляры ресурсных зданий и отсутствующие постройки. Параметры выбранной цели не подменяют реальные требования. `construction.py` читает native-каталог, лимит количества при текущей ратуше, размеры, ресурсы и `newPosValid`. Новая постройка создаётся только при отсутствии такого типа; после серверного принятия повторный запуск не создаёт дубликат.

Реальные результаты:
