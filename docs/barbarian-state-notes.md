## Полный сохраняемый цикл

`BarbarianCycle` сохраняет в SQLite preference отдельную от копируемых профилей сессию: задача/персонаж/сервер, intent перед вводом, troopId/charId, исходные максимумы и городской учёт, число принятых платных атак. Другая задача не может присвоить армию. Отмена после отправки восстанавливается по сохранённому intent без повторного ввода. Предел боёв, резерв AP и порог здоровья завершают заход подтверждённым возвратом; отсутствие армии само по себе не подтверждает сохранность войск.

Живой цикл из четырёх отдельных запусков Engine с общей SQLite-сессией:

- `mirage-barbarian-owned-cycle-start-20261112-a`:17.59с, новая армия с удержанием.
- `mirage-barbarian-owned-cycle-second-20261112-a`:13.01с, следующая цель той же полевой армией, только910/170 и755/230 вместо New Troop/Send.
- `mirage-barbarian-owned-cycle-recall-20261112-a`:6.39с, возврат по порогу здоровья,920/145→518/346→город.
- `mirage-barbarian-owned-cycle-complete-20261112-a`:0.71с, без ввода, городской учёт здоровых/раненых сошёлся, сессия очищена.

На этом этапе положительный маршрут ограничен Сунь-цзы без талантов и первым уровнем. Настройки других командиров/уровней должны проходить отдельную проверку до включения маршрута. Фарм цепочкой с бесплатными дополнительными противниками ещё не подтверждён.
