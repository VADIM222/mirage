Подтверждённые пассивным чтением имена/состояния:

- Тип объекта пещеры10. Посещение проверяется по двум картам `ScoutData.OpenCaveIdMap` и `OpenCaveGhostIdMap`, а не только первой.
- `message_pb.MapScout`: Idle1, Explore2, Chase3, Return4, Investigate5, Dead6, Training7, Station8, Building9. `const_pb.NormalCav=0`.
- `IsGoToCave` проверяет Chase3, `targetSubType=NormalCav`, `targetSubId`; `IsCaveInvestigating` — Investigate5 и `targetId`. Время исследования берётся из `startTime/endTime` того же разведчика.
- `MapUnkownCityPopUp.ClickAdventure` различает обычную пещеру и `cave.isClientCave` радара. Обычная открывает `MapUISelectScouts`, учитывая отдельный переключатель удержания после исследования. Радарный путь вызывает собственный сценарий и не входит в обычную разведку.
- `MapUISelectScouts.ClickStartScout` для объекта вызывает обычный `ScoutTarget`; сетевые поля назначения: Idx, TargetId, Station, IsStayAfterBattle. Бот не вызывает этот обработчик: он только читает данные формы и нажимает ADB.
- `HandleMapScout` обновляет `charId`, `targetId`, `targetSubId`, `targetSubType`, `targetCharType`, состояние/время и данные цели; обновление пещеры сопровождается EVENT_UPDATE_CAVI_INFO. Эти имена сами по себе ещё не подтверждают конкретную отправку.
- Почтовые обработчики включают `netMailAdjustScoutDiscover` и `MailHelper.GetCanInvastigateCave`; связь настоящего завершения с предметом/почтовой наградой ещё требует наблюдения.

Свидетельства: `mirage-cave-contract-methods-20261112.json`, `mirage-cave-dispatch-contract-20261112.json`, `mirage-cave-state-and-mail-contract-20261112.json` в `%TEMP%\opencode`.

Для поиска свежей цели добавлен ограниченный `research/explore_until_cave.py`: обычный проверенный Engine тумана, естественные возвраты разведчика, максимум8 новых отправок/15мин по умолчанию, остановка при обнаружении пещеры. Новое событие кнопки «Стоп» прерывает наблюдения/ввод, даже если основной профиль уже стоял на паузе. Время и таймеры игры не изменяются.

`MailHandler.netMailAdjustScoutDiscover` читает `ApiScoutDiscoverReport`: Pos.X/Y, Type, CaViId, ExtInfo, HeroId. Это письмо об обнаружении цели; оно не является доказательством её исследования или получения сундука (`mirage-cave-mail-reward-fields-20261112.json`).
