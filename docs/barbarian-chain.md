# Обычный фарм и отдельный фарм цепочкой

## Обход карты вместо игрового поиска

Цепочка не использует штатный поиск NPC. Для осмотра бот зажимает кнопку города800мс и выбирает **«Ресурсы»** (значок дерева). Это только масштаб карты цепочки: native `WorldMgr.viewHeight=4500`,при котором ещё видны NPC. **Задача сбора ресурсов не менялась и продолжает использовать обычный поиск.**

В этом масштабе ширина видимой области выросла примерно с58.6 до195.2 world units (в3.33раза). Прежний `CityBuildUIMenu.curLodDistance` при этом не изменяется,поэтому координаты цепочки теперь вычисляются из фактических четырёх углов `WorldMgr.cameraParams.corners`. Независимое зажатие земли500/350 подтвердило точку8010.481934/19085.322266; расхождение новой проекции укладывается в округление пикселя. Общий `@city_camera` и чтение камеры сбора ресурсов сохранены.

Обход расширен до **радиуса450** вокруг своей армии/города вместо прежнего выбора в90. Шаг рассчитывается по реальному обзору с перекрытием (в живой проверке110×85); за вызов осматриваются до3 участков,следующий пакет назначается через1с вместо5. Используются широкие жесты и подтверждённое устойчивое положение камеры вместо фиксированной паузы1.5с после каждого мелкого сдвига. `barbarian-survey:<instance>` сохраняет курсор,шаг,круг,количество участков и отклонённые цели; состояние привязано к игроку/серверу/паре/диапазону и своей армии. Версия курсора2 сбрасывает прежнюю малую сетку.

Перед выбором NPC игра штатным зажатием приближает нужную точку к тактическому масштабу; точный ID повторно проверяется уже там. Далёкая группа достигается бесплатными участками по60 world units с durable intent/квитанцией и лимитом переходов; оплаты длинного неподтверждённого городского марша нет. После отказа плана цепочка возвращается к широкому обзору. Камера остаётся на карте,без входа в город.

Выбираются уже существующие свободные обычные NPC по native-сцене, с приоритетом большего допустимого скопления (3+ перед2). Минимальный и максимальный уровни цепочки теперь относятся **ко всем целям группы**, а не к вкладке игрового поиска. Изолированный NPC не открывается ради последующего отказа плана. После выбора точные ID, состав, здоровье, геометрия и стоимость повторно проверяются до оплаты. Сам обход не выводит армию и не расходует AP.

Если скопления нет, цель ушла или проверка плана отклонена, окно закрывается обратно **на карту** и осмотр продолжается. Уже принадлежащая цепочке армия остаётся в поле; пустой участок не переводит lease в recall_intent. Возврат сохраняется при лимите платных атак, недостатке AP, пороге здоровья и смене пары. Обычный фарм по-прежнему имеет отдельный игровой поиск.

При ленивых таблицах используется только эта версия/командир/навык. Если загружена лишь одна строка, отсутствующая дополняется только при совпадении всех уже прочитанных полей; конфликтующая native-строка не заменяется. Сунь-цзы сохраняет свой сектор. ## Общая механика

Оба режима управляют принадлежащей персонажу армией в поле. Для следующей цели выбирается эта армия, а не новая из города. Удержание подтверждается игровым состоянием; стоимость каждого намеренно начатого боя читается из текущего UI/состояния выбранного марша. Скидка не вычисляется по придуманной последовательности50/48/46. Предметы AP и ускорения автоматически не расходуются.

Обычный режим выбирает одну подходящую цель. Цепочка дополнительно подбирает скопления и использует положение армии/направление атаки для попадания площадного навыка по соседям. Бот учитывает только реально вступивших в бой противников по данным памяти, списанию AP и результатам; обещать фиксированные2–3 бесплатные цели на каждый бой нельзя.

## Настройки

Отдельные профили задач в Desktop/Telegram: командир, уровень целей, резерв AP, предел боёв за заход, порог здоровья для завершения и возвращения. Конкретные начальные значения — выбор реализации после живой проверки; пользователь пока не задавал числовых порогов. По кнопке «Стоп» прекращаются ввод и наблюдатели; оставшаяся в поле армия не получает дополнительных команд после остановки.

Задачи не должны одновременно распоряжаться одной армией. Сохраняется её идентичность: персонаж/сервер, troopId/charId, командир и исходный состав. Во время боя новая платная атака не запускается; дополнительные противники от навыка учитываются в текущем бою. По завершении/порогам — обычный возврат и подтверждение состава/раненых.
