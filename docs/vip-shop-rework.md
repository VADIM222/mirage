# VIP-магазин: обязательная переделка

Уточнение пользователя,2026-11-11: магазин содержит большой вертикально прокручиваемый список. На текущем новом персонаже полный магазин ещё не открыт; переделку проверить при открытии.

## Требуемое поведение

- Пройти весь список сверху вниз, включая товары за пределами первого экрана. Подтвердить конец списка и не пропускать товары после изменения остатков/перестроения строк.
- За обычные ресурсы скупать всё доступное. Проверять настоящую валюту, цену, доступный остаток и настроенные резервы ресурсов, а не ограничиваться четырьмя заранее заданными товарами за еду.
- Для каждого товара за гемы предоставить отдельную галочку «покупать / не покупать» в Desktop и Telegram. Все такие галочки по умолчанию выключены; покупается только явно выбранное.
- Каждая покупка подтверждается точным изменением валюты, инвентаря и остатка товара. Остановка немедленная; после возобновления сверять текущий остаток, не повторять уже принятую покупку.
- Настройки сохраняются атомарно и не затирают параллельные правки Desktop/Telegram.
