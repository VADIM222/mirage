# Основной и второй командиры

В настройках **«Варвары»** и **«Цепочка»** — два отдельных списка по именам. Второй слот имеет вариант **«Без второго командира»**. Пара сохраняется автоматически и независимо для каждого режима/экземпляра. В Telegram доступны те же именованные списки со страницами по12 командиров.

Список берётся из `HeroHandler.HeroMap` текущего персонажа. Имена читаются из локализации установленной игры через проверенный native data-reader `eng.rawGetGameText`; поэтому язык имён соответствует игре. Кеш `commander-roster:<instance>` привязан к PlayerID. При смене персонажа прежний кеш не используется. Каталог вложен в проекцию `player`, лимит64 полей атомарного боевого снимка сохранён.

Старые профили продолжают использовать основной3/второй0. Один командир не может занимать оба слота. Выбор прежнего второго основным очищает второй слот; выбор основного с менее чем тремя звёздами также очищает второго.

## Автоматизация

Бот открывает городскую форму, назначает выбранных командиров по native ID/слоту/порядку списка, убирает осадные из подтверждённых боевых строк и сам выводит отряд. Фильтры редкости и типа войск проверяются по native-состоянию до выбора строки. Геометрия текущего picker проверена для первых четырёх двухколоночных строк отфильтрованного списка; если нужный командир ниже, ввод блокируется — неподтверждённая прокрутка не выполняется.

Квитанции городского выхода, полевой атаки, бесплатного подхода и боевого отвода сохраняют **обоих** командиров с точными номерами слотов. Смена настройки пары во время своей полевой сессии приводит к возврату прежней армии перед формированием новой. Ручная армия не присваивается режиму.

Для обычного варвара городская стоимость определяется native-базой цели и AP-талантами основного командира. Удержание полевой армии дополнительно учитывает её APR и native `ActualCost` селектора; принятие отправки требует точного списания AP. Таланты второго командира не подменяют таланты основного. Резерв повторно проверяется перед сохранением paid intent.

Цепочка читает геометрию активного навыка выбранных командиров. Поддерживаются подтверждённый сектор и прочитанная в бою круговая область Чжугэ179/Skill243/Area15. Измеренные fallback Сунь-цзы и Чжугэ применяются каждый только к своему навыку/непробуждённому состоянию/проверенной версии, в том числе во втором слоте. Неизвестному навыку эта геометрия не приписывается. Собственный отчёт по-прежнему обязателен для бесплатной победы. Цепочка осматривает карту самостоятельно без штатного поиска NPC и не возвращает армию из-за отсутствия скопления: [маршрут](barbarian-chain.md).

Частичная загрузка таблиц поддержана отдельно: если `skill_Client` уже прочитан, а `skill_Area` ещё nil (или наоборот), недостающая строка дополняется только при полном совпадении присутствующих планировочных полей с проверенной геометрией. В пользовательской сессии PID3553 обнаружен именно этот случай, а активный навык Чжугэ уже повышен пользователем доL5. Живое повторное чтение подтвердило круг15/Radius10 и корректный источник `verified-native:1.1.12.20:243:15`; настройки/навыки диагностикой не менялись (`mirage-chain-map-restored-20261114-an/live-partial-geometry-fixed.json`).
