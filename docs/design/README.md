# Выбранный интерфейс

Вариант A «Графит и песок», утверждён пользователем. Компоновка — как в интерактивном макете: боковая навигация, таблица экземпляров, детали выбранного экземпляра и постоянно видимый журнал. Исполняемый интерфейс реализован настоящими виджетами PySide6.

Основной фон `#151618`, поверхности `#1B1C1F` / `#222326`, разделители `#303136`, текст `#E7E7E9`, вторичный текст `#A5A6AF`, акцент `#DFB47A`.
